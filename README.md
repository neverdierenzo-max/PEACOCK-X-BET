# PEACOCK X BET APK

This project wraps the existing PEACOCK X BET HTML demo inside an Android WebView.

## GitHub
Upload the contents of this folder to the repository root. Keep `.github/workflows/build-apk.yml`.

Then open:
Actions -> Build APK -> Run workflow

The generated APK is uploaded as the artifact:
PEACOCK-X-BET-debug-apk

Note: this is the existing demo/prototype HTML wrapped as an APK; it does not turn demo/local browser data into a real-money betting backend.
